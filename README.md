
## Reglas rápidas

- Un solo repositorio por unidad; una carpeta por cada tarea o taller.
- Commits pequeños y frecuentes, con mensajes claros (ver INSTRUCTIVO, paso 4).
- **Nunca** subas contraseñas, llaves `.pem`, credenciales de AWS ni archivos `.env`.
